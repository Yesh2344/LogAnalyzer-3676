# LogAnalyzer 📊

[![Go Report Card](https://goreportcard.com/badge/github.com/yourusername/loganalyzer)](https://goreportcard.com/report/github.com/yourusername/loganalyzer)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

LogAnalyzer is a production‑ready Go application that parses server log files, aggregates statistics, and outputs a concise report. It demonstrates modern Go practices, clean architecture, robust error handling, and comprehensive testing.

## Features

- ✅ Configurable via `.env` or environment variables
- 📂 Recursive log directory scanning
- 🧮 Real‑time aggregation of log levels (INFO, WARN, ERROR, DEBUG)
- 📈 Output in JSON or plain text
- 🪵 Structured logging with Logrus
- 🧪 100 % unit test coverage for core logic
